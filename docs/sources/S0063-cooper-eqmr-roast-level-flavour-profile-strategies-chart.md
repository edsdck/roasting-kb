# S0063 — Cooper: a chart of phase times and the flavour each is meant to give

**Author:** Anne Cooper · **Type:** one-page chart (scanned PDF, read from an image) · **Grade:** C · **Heat context:** n/a · [Original](https://eqmr.com.au/_files/ugd/5d1111_23d7f837b747476490133a960eafabd9.pdf)

## Summary
A single chart lists twelve "strategies" from Light to Dark. Each is a bar of three timed phases plus a flavour description and, for some, a process (washed or natural). The phases are not named on the chart; by colour (green, yellow, brown) and by the matching phase list in S0057 they read as preparation to yellow, Maillard to first crack, and development after first crack (inference). The Light entries run 4:30-5:30 / 3:30-4:00 / 1:00-1:30. The chart offers no data or tasting results and says taste decides.

## Key claims
1. **C1** — Light strategies and their stated flavour (phase times as printed, phase 1 / 2 / 3):
   - Light: 5:00-5:30 / 4:00 / 1:30 — sweet, light, round, good body (washed)
   - Light 5: 5:00-5:30 / 4:00 / 1:00 — sweet, light, round, good body (natural)
   - Light 3: 5:00-5:30 / 3:30 / 1:30 — light body and sweetness, good acidity/fruit (washed)
   - Light 2: 4:30 / 3:30 / 1:30 — bright, clean, low body and sweetness, good acidity (washed)
   - Light 4: 4:30 / 3:30 / 1:00 — bright, clean, low body and sweetness, good acidity/fruit (natural)
2. **C2** — Medium strategies: Medium 5:00-5:30 / 4:00 / 2:30 (more origin notes, sweet, round, good body; washed); Medium 2 5:00-5:30 / 3:30 / 2:30 (less sweet, less body; washed); Medium 4 5:00-5:30 / 4:00 / 2:00 (good body, sweet and light; natural); Medium 3 5:00-5:30 / 3:30 / 2:00 (less sweet, less body, more fruit/acidity); Medium/Long 5:00-5:30 / 4:30 / 2:30 (very round sweetness and body).
3. **C3** — Darker strategies: Med/Dark 5:00-5:30 / 4:00 / 3:00 (rich, sweet, dark chocolate, caramel, toffee); Dark 5:00-5:30 / 4:00 / 4:00 (heavy, rich, sweet, dark chocolate, roasty).
4. **C4** — Reading across rows: with the same first and last phase, cutting the middle phase from 4:00 to 3:30 moves the description from "sweet, round, good body" to "less sweet, less body, more acidity/fruit" (Light vs Light 3; Medium vs Medium 2; Medium 4 vs Medium 3). This is the chart's pattern, not a tested result.
5. **C5** — The chart is to be used with a separate parameters chart for end roast level and is explicitly a guide.
   > "Best used along with the Parameters Chart for defining End Roast Level" — *footnote*
   > "Always Remember that Taste is the Defining Factor & that this is a Guide Only!" — *footnote*

## Relevance to Skywalker (IR, 350 g)
*Gatherer judgement:* A compact companion to S0057 (the 2026 light-roast recipe: development 1:00-1:20). It gives one practitioner's expected cup shift for the middle phase and for the first phase, which bears on gap 11 (browning length) and gap 1 (development 1:00-1:30 labelled "sweet, round"). Because machine, batch size and colour are missing, the times cannot be applied to a Skywalker as targets; use them as relative effects and test them.
